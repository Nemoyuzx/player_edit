# Video Arrow Key Rebind

一个同时支持 Chrome 和 Edge 的浏览器扩展，用来重写网页 HTML5 视频的左右方向键行为。

当前主要使用平台为“启航教育”，目的是让平台上的视频播放器获得更接近 B 站的键盘播放控制体验，方便在学习考研数学课程时使用。

- 短按左方向键：快退 5 秒
- 短按右方向键：快进 5 秒
- 长按右方向键：进入 3 倍速快进，松开恢复原速
- 长按左方向键：进入近似 3 倍速快退，松开停止并恢复播放状态

页面顶部会显示简洁提示层，告诉你当前是短按跳转还是长按倍速状态。

现在也支持可配置选项：

- 启用或禁用扩展
- 开关页面提示层
- 自定义短按跳转秒数
- 自定义长按判定时间
- 自定义长按左右键的倍速
- 设置全部站点生效、仅白名单生效、排除黑名单三种模式

## 安装方式

### Chrome

1. 打开 `chrome://extensions/`
2. 开启“开发者模式”
3. 点击“加载已解压的扩展程序”
4. 选择当前目录
5. 点击浏览器工具栏里的扩展图标，会直接打开设置页

### Chrome 操作教程

1. 进入启航教育课程页面并开始播放视频。
2. 首次使用时点击浏览器右上角扩展图标，打开设置页。
3. 根据需要设置短按跳转秒数、长按判定时间、快进倍速和快退倍速。
4. 回到视频页面后，短按左右方向键可进行 5 秒跳转，长按则进入倍速快进或快退。
5. 如需只在启航教育生效，可将站点模式改为白名单，并填写对应域名。

### Edge

1. 打开 `edge://extensions/`
2. 开启“开发人员模式”
3. 点击“加载解压缩的扩展”
4. 选择当前目录
5. 点击浏览器工具栏里的扩展图标，会直接打开设置页

### Edge 操作教程

1. 在 Edge 中打开启航教育课程视频页面。
2. 点击浏览器右上角扩展图标进入设置页。
3. 打开 `启用扩展`，并按需调整跳转秒数和长按倍速参数。
4. 返回播放器页面后，直接使用键盘左右方向键控制视频。
5. 如果不希望影响其它网站，可在站点规则中只保留启航教育相关域名。

## 设置页说明

- `启用扩展`：总开关
- `显示页面提示`：关闭后仍会生效，只是不再显示顶部提示层
- `短按跳转秒数`：左右方向键短按时的固定跳转距离
- `长按判定时间`：按住超过这个时间后进入长按模式
- `长按右键快进倍速`：控制长按右方向键时的播放速率
- `长按左键快退倍速`：通过定时回退模拟快退速度
- `站点规则`：支持填域名或 URL，例如 `bilibili.com`、`https://www.youtube.com/watch?v=...`

`example.com` 会匹配主域名和子域名。白名单模式下，如果列表为空，则默认没有任何站点生效。

## 打包

如果你想生成一个可分发的压缩包，可以在当前目录执行：

```sh
sh package.sh
```

生成结果会放在 `dist/video-arrow-key-rebind.zip`。

## 说明

- 该扩展基于 Manifest V3，Chrome 和 Edge 都可直接加载。
- 只会在页面存在可见 HTML5 `video` 元素时拦截左右方向键。
- 当焦点位于输入框、文本域或可编辑区域时，不会拦截按键。
- 某些站点如果使用封闭播放器、DRM 容器或非标准视频层，可能无法完全覆盖其快捷键逻辑。
